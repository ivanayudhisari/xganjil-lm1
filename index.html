Pertemuan 1

Materi Struktur Data

Cara terorganisir untuk menyimpan, mengatur, dan mengelola data dalam memori komputer.

1. Array (Larik)

Struktur data yang menyimpan sekumpulan elemen data dengan tipe yang sama secara berurutan dalam lokasi memori yang bersebelahan. Setiap elemen diakses langsung melalui Indeks (Posisi).

Analogi Dunia Nyata:

Rak Sepatu Loker: Setiap slot memiliki nomor tetap (0, 1, 2, 3). Untuk mengambil sepatu di slot 3, Anda bisa langsung membukanya secara instan tanpa harus mengecek slot 0, 1, atau 2 (Direct Access).

Kelebihan: Akses cepat O(1) lewat indeks.
Kekurangan: Ukuran bersifat statis (tetap).
Contoh Kode Python: Array 
# Deklarasi Array (List di Python)
rak_sepatu = ["Sepatu Merah", "Sepatu Biru", "Sepatu Hitam"]

# Akses Elemen via Indeks (Direct Access)
print(rak_sepatu[0]) # Output: Sepatu Merah
print(rak_sepatu[2]) # Output: Sepatu Hitam
Visualisasi Indeks Array:
Indeks 0
Data A
Indeks 1
Data B
Indeks 2
Data C
Indeks 3
Data D

2. Linked List (Daftar Berantai)

Kumpulan elemen data (disebut **Node**), di mana setiap node berisi data dan sebuah **Pointer (Penunjuk)** yang mengarahkan ke node berikutnya. Berbeda dari array, posisi memori tidak harus berdampingan.

Analogi Dunia Nyata:

Gerbong Kereta Api: Setiap gerbong (node) menyimpan penumpang (data) dan disambungkan dengan pengait (pointer) ke gerbong di belakangnya. Menambah gerbong baru di tengah cukup melepas dan menyambung rantai pengait.

Kelebihan: Ukuran dinamis & mudah insert/delete.
Kekurangan: Akses data harus sekuensial dari Head.
Contoh Kode Python: Linked List Node 
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

# Membuat Node
node1 = Node("Gerbong 1")
node2 = Node("Gerbong 2")
node1.next = node2 # Menghubungkan Pointer

3. Stack (Tumpukan - LIFO)

Struktur data linear dengan prinsip LIFO (Last-In, First-Out). Elemen yang terakhir dimasukkan akan menjadi elemen pertama yang dikeluarkan. Operasi utama: Push (Tambah) & Pop (Hapus).

Analogi Dunia Nyata:

Tumpukan Piring di Dapur: Piring yang ditaruh paling akhir (di posisi paling atas) adalah piring yang pertama kali diambil saat hendak makan.

Contoh Kode Python: Stack 
stack = []
stack.append("Piring 1") # Push
stack.append("Piring 2") # Push
piring_diambil = stack.pop() # Pop -> Output: Piring 2

4. Queue (Antrean - FIFO)

Struktur data dengan prinsip FIFO (First-In, First-Out). Elemen yang pertama kali datang adalah yang pertama kali dilayani. Operasi utama: Enqueue (Masuk Antrean) & Dequeue (Keluar Antrean).

Analogi Dunia Nyata:

Antrean Kasir Supermarket: Pembeli yang datang paling awal akan dilayani dan selesai transaksi terlebih dahulu secara adil.

Contoh Kode Python: Queue 
from collections import deque
queue = deque()
queue.append("Pembeli A") # Enqueue
queue.append("Pembeli B") # Enqueue
dilayani = queue.popleft() # Dequeue -> Output: Pembeli A

5. Tree (Pohon Hierarki)

Struktur data non-linear ber-hierarki yang dimulai dari **Root (Akar)** dan bercabang ke **Node Anak (Child)**.

Analogi Dunia Nyata:

Struktur Organisasi Sekolah / Silsilah Keluarga: Posisi tertinggi diawali dari Wali Kelas / Kepala Sekolah (Root), lalu membawahi Ketua Kelas, Sekretaris, dan Anggota.

Contoh Kode Python: Tree Node 
class TreeNode:
    def __init__(self, name):
        self.name = name
        self.children = []

root = TreeNode("Kepala Sekolah")
root.children.append(TreeNode("Ketua Kelas"))
Pertemuan 2

Materi Algoritma Standar

Prosedur langkah demi langkah untuk Pencarian (Search) dan Pengurutan (Sort).

1. Linear Search (Pencarian Berurutan)

Memeriksa setiap elemen data satu per satu dari awal sampai akhir hingga target ditemukan. Tidak memerlukan data yang terurut.

Kompleksitas Waktu: O(n)
Analogi RPM: Mencari kunci mobil yang hilang di rumah dengan mengecek kamar depan, kamar tengah, lalu dapur secara bertahap.
Python Code 
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i # Ditemukan di indeks i
    return -1

2. Binary Search (Pencarian Biner)

Membagi interval pencarian menjadi dua bagian secara berulang. Syarat Mutlak: Data Wajib Terurut!

Kompleksitas Waktu: O(log n)
Analogi RPM: Mencari kata di kamus bahasa Indonesia dengan membuka tengah buku lalu membuang paruh yang tak sesuai.
Python Code 
def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target: return mid
        elif arr[mid] < target: low = mid + 1
        else: high = mid - 1
    return -1

3. Bubble Sort (Pengurutan Gelembung)

Membandingkan dua elemen berdekatan dan menukarnya jika posisinya salah. Nilai terbesar naik ("menggelembung") ke posisi paling belakang secara bertahap.

Analogi RPM: Mengurutkan koin pecahan di saku baju dari nominal terkecil hingga terbesar.
Python Code 
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]

4. Insertion Sort (Pengurutan Penyisipan)

Mengambil satu elemen baru dan menyelipkannya ke celah yang tepat pada sub-array yang sudah terurut.

Analogi RPM: Mengurutkan kartu remi di tangan saat baru diambil satu per satu dari meja.
Python Code 
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and key < arr[j]:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key

5. Selection Sort (Pengurutan Seleksi)

Mencari elemen terkecil dari bagian yang belum terurut, lalu menukarnya ke posisi paling depan.

Analogi RPM: Mengurutkan pakaian berukuran S hingga XL di lemari baju.
Python Code 
def selection_sort(arr):
    for i in range(len(arr)):
        min_idx = i
        for j in range(i+1, len(arr)):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
